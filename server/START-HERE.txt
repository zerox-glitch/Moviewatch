MOVIEWATCH - START HERE  (your Python 3.13 already works - nothing to install)
===============================================================================

IMPORTANT: never copy commands from chat windows - chats turn filenames and
URLs into  [something](http://...)  which breaks them. Copy from THIS FILE
or use the copy buttons on the website instead.

STEP 1 - CLEAN UP THE BROKEN DOWNLOAD
-------------------------------------
Open PowerShell (Start, type powershell, Enter) and run:

    Remove-Item -Path "$HOME\Desktop\*moviewatch*" -Force

(that deletes the junk error-page file saved earlier)

STEP 2 - GET THE REAL moviewatch.py (pick ONE way)
--------------------------------------------------

WAY A - from the chat/file viewer (one click):
    the agent opened moviewatch.py in your file viewer - use its Download
    button and save it to your DESKTOP as  moviewatch.py
    (check it is NOT named moviewatch.py.txt - enable
     View > Show > File name extensions in Explorer)

WAY B - from GitHub in your BROWSER (click the link, do not copy it):
    https://github.com/zerox-glitch/Moviewatch/blob/arena/01a07e2b-moviewatch/server/moviewatch.py
    click the  "Download Raw File"  button near the top, save to Desktop.

WAY C - PowerShell (type it BY HAND, or copy from this file):
    cd $HOME\Desktop
    curl.exe -L -o moviewatch.py https://raw.githubusercontent.com/zerox-glitch/Moviewatch/arena/01a07e2b-moviewatch/server/moviewatch.py

CHECK: the file must be about 30 KB. Tiny file = error page = delete and
retry.  Type  Get-Item $HOME\Desktop\moviewatch.py  to see its size.

STEP 3 - RUN THE SERVER (same PowerShell window)
------------------------------------------------
    cd $HOME\Desktop
    python moviewatch.py

- a folder picker opens: choose the folder with your movies
- success = big "MOVIEWATCH media server" banner + "Videos found: N"
- LEAVE THAT WINDOW OPEN - it is the server
- if "Videos found: 0": press Ctrl+C, then run it pointing at your folder:
    python moviewatch.py --dir "C:\Users\Admin\Videos\Movies"

STEP 4 - PUBLIC LINK (SECOND PowerShell window)
-----------------------------------------------

(first time only:  winget install --id Cloudflare.cloudflared )
Copy the https://xxxx.trycloudflare.com address it prints.

STEP 5 - ON THE WEBSITE
-----------------------
Create Room -> paste the address -> Connect -> pick the movie ->
"Copy invite link" -> send it -> press play. Your partner just opens it.

IF ANYTHING FLASHES AND CLOSES
------------------------------
Launch from PowerShell (steps 3/4) - the message stays visible and tells you
exactly what is wrong. start-moviewatch.bat also works: it finds py, python,
python3, or the Microsoft Store Python automatically.

Keep the PC plugged in and awake (Settings > System > Power > Sleep: Never).
