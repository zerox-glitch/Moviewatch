-----------------------------------------------------------------------
1. Open PowerShell (Start button, type "powershell", Enter).
2. Paste these three lines, pressing Enter after each:

     cd $HOME\Desktop
     curl.exe -L -o moviewatch.py https://raw.githubusercontent.com/zerox-glitch/Moviewatch/arena/01a07e2b-moviewatch/server/moviewatch.py
     python moviewatch.py

   pointing at your real movies folder, e.g.:

     python moviewatch.py --dir "C:\Users\Admin\Videos\Movies"

   "Videos found: N". LEAVE THAT WINDOW OPEN - it is the server.

-----------------------------------------------------------------------
